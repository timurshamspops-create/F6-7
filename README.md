# F6-7 League — версия для GitHub Pages

Полностью статический вариант сайта: нет сервера, нет базы данных, нет входа администратора. Все данные (команды, гонщики, гонки, ссылки) лежат в одном файле — **`client/src/data.js`** — и вшиваются в сайт при сборке.

**Как обновить сайт:** отредактировали `client/src/data.js` → `git push` → GitHub сам пересобирает и публикует сайт за 1-2 минуты (это делает `.github/workflows/deploy.yml`).

---

## 1. Выложить на GitHub

```
cd f6-7-league-pages
git init
git add .
git commit -m "F6-7 league"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

## 2. Включить GitHub Pages

1. В репозитории на GitHub: **Settings → Pages**
2. **Build and deployment → Source** → выбрать **GitHub Actions** (не «Deploy from a branch»!)
3. Перейдите во вкладку **Actions** — там уже должен идти или завершиться workflow «Deploy to GitHub Pages» (он запустился автоматически после push)
4. Когда появится зелёная галочка — в **Settings → Pages** сверху появится ссылка вида `https://ваш_логин.github.io/название_репо/` — откройте, проверьте

## 3. Подключить домен f6-7.com

1. **Settings → Pages → Custom domain** → введите `f6-7.com` → Save
2. В **Cloudflare → f6-7.com → DNS → Records** добавьте **4 A-записи** на корневой домен (Name: `@`) со значениями:
   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```
   Удалите старые записи, указывавшие на Netlify/cloudflared, если они остались
3. Облако в Cloudflare можно оставить серым (DNS only) на первое время, пока GitHub не выпустит сертификат — потом можно включить оранжевое (Proxied), если хотите CDN Cloudflare поверх
4. Вернитесь в **Settings → Pages** — когда DNS применится (обычно до пары часов), появится галочка и включится опция **Enforce HTTPS** — включите её

## Как редактировать сайт

Открываете `client/src/data.js` в любом текстовом редакторе (там подробные комментарии на русском) — там 4 массива:

- `TEAMS` — команды
- `DRIVERS` — гонщики (`teamId` должен совпадать с `id` команды)
- `RACES` — гонки и результаты (место в чемпионате считается отсюда автоматически)
- `RESOURCES` — ссылки

Добавить новую гонку — скопируйте один блок из `RACES`, вставьте в конец, поменяйте `id`, дату и результаты. Сохранили → закоммитили → запушили → сайт обновился сам.

## Проверка локально перед публикацией (необязательно)

```
cd client
npm install
npm run dev
```
Откроется адрес вида `http://localhost:5173`.

---

## Важно понимать про эту версию

- **Нет входа/админки на сайте** — все правки только через код и `git push`, как вы и просили
- Подходит, если результаты публикует один человек с доступом к репозиторию (или несколько через Pull Request)
- GitHub Pages полностью бесплатен для публичных репозиториев
